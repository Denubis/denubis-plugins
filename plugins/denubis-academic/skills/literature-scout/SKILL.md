# Literature scout

Discover candidate sources for a bounded research question. Keep bibliographic
identity, relevance, and support for a substantive claim as separate judgements.
A resolved DOI proves neither relevance nor what a paper concludes.

## Set the search boundary

Read the project instructions and research brief. Infer the question, seed
sources, inclusion/exclusion criteria, date range, languages and source types;
ask only for missing decisions that change the search. State a practical search
budget and stopping point. An exploratory search is not a systematic review.

Read [search and verification](references/search-and-verification.md) for the
query helper, evidence records, and verification handoff. Search public sources
without requiring Zotero. Load [using-bibliography](../using-bibliography/SKILL.md)
before checking the local collection or preparing full text. Metadata discovery
may run outside Zotero; acquiring or reading source documents follows the
[scout collection and reading gate](references/search-and-verification.md#scout-collection-and-reading-gate).

## Discover, then verify

1. Search more than one relevant index or publisher source, varying terminology
   and checking known seeds. Record queries, dates, limits, unavailable services,
   and which result pages were inspected. Retain preprints, books, datasets and
   DOI-less work when in scope; distinguish versions rather than merging by title.
2. Follow backward and forward citations from useful seeds within the agreed
   budget. Explain why a candidate fits using evidence actually read. Label
   title-only, abstract-only and full-text assessments separately.
3. Save the candidate table and search log before verification. Check that the
   identity handoff includes every proposed bibliographic field in the table,
   with its source, including observations outside the registry response. Give a fresh
   reviewer the table, original brief and source identifiers, without the
   discovery agent's reasoning or hints about suspect rows. Use delegation only
   when permitted; otherwise do a separate check and disclose that it was not
   independent. A missing reviewer leaves independent verification pending.
4. Re-query each candidate's metadata, checking all named authors, title,
   publication/version, year and identifier. Resolve discrepancies against the
   publisher or appropriate registry. Preserve original and corrected values
   with evidence. A service failure is an incomplete check; a registry miss is
   not global proof that a work does not exist.
5. Before full-text reading, complete the scout collection and reading gate:
   put sources worth reading in the scout subcollection and escalate missing
   full text to the user. Then verify relevance and substantive synthesis separately.
   Revise conclusions affected by corrections; do not attach a verified label
   to an unchanged thematic narrative merely because its DOI table passed.

Use exact returned Zotero citekeys for known items. For unknown items retain the
DOI/URL and candidate identifier until resolution; never manufacture a citekey.
Route acquisition through using-bibliography, using existing user authorisation
for the scout's scope and destination; otherwise preview the batch for approval.
Do not download standalone PDFs, even for metadata verification. Include the
collection, acquisition boundary and reading-gate state in every reviewer handoff.
Never hand-edit a BBT bibliography.

## Deliver and resume

Return the ranked source table, evidence-backed relevance notes, corrections,
verification coverage (checked/total, with unavailable fields), search log and
remaining gaps. Label an absence as a gap in the searched collection unless a
documented search supports a broader claim. Report citation counts with their
provider and retrieval date; do not rank quality by citation count alone.

Persist the report and saved responses in the project's chosen research location
or a stated scratch directory. Resume from those artifacts, rechecking changed
or unresolved records. Stop on the search budget, unavailable services or an
unresolved disagreement; do not run a correction loop until it returns agreement.

For source-grounded entries rather than discovery, hand off to
[annotated-bibliography](../annotated-bibliography/SKILL.md).
