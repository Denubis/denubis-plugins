# Remove one generated cache

Resolve the exact directory, show that it is generated and recoverable, and confirm that
the request authorises deletion of that target. Inspect it before deletion. Refuse a broad,
unresolved, or source-containing target. After deletion, read back the parent state and
report exactly what was removed.
